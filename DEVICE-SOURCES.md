# Real-device preset references

Responsive Mockup Studio uses real commercial device models, native resolutions, aspect ratios, curvature values, and front-view dimensions as preset references. The shipped shells are original CSS/Canvas technical constructions so preview and high-resolution export stay identical and offline; manufacturer product photos are not redistributed. Manufacturer geometry is locked for real presets and physically editable only in Custom Frame.
