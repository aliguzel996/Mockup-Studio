Version 1.3.8 removes the custom WebView context that caused remote sites such as /subpix-Lab/ to fail with “not permitted” on Android. Website previews now use Android's supported Activity context, while controlled 1:1 scaling preserves desktop viewport dimensions without allocating an oversized GPU surface. Test patterns open without requesting camera access; if the user activates a website camera feature, video-only camera permission is requested and live preview is supported.
