# Responsive Mockup Studio

## Short description

Preview live websites in configurable device frames and export polished mockups.

## Full description

Responsive Mockup Studio brings responsive website preview, device framing, composition, and export into one workspace.

Enter a website URL, switch between desktop, tablet, phone, or custom viewport sizes, and place the live page inside a configurable device. Adjust frame color, material, supported parts, shadows, background colors, images, and gradients without rebuilding the composition in a separate image editor.

On a tablet, use one finger or a pen to reposition the device and pinch with two fingers to zoom. The interface supports portrait and landscape layouts, touch-friendly controls, system file selection, and direct export to the device Downloads folder.

Key features:

- Live responsive website preview
- Custom computer, tablet, and phone frames
- Preset aspect-ratio frames and favorites
- Editable colors, materials, shadows, and removable device parts
- Reusable saved custom devices
- Black, white, transparent, image, and multi-stop gradient backgrounds
- 1:1, 4:5, and 16:9 composition guides
- PNG, transparent PNG, JPG, WebP, and SVG export
- Local bookmarks, recent URLs, projects, devices, and preferences
- No account, advertising SDK, analytics SDK, or subscription

Websites can restrict whether they are displayed or modified inside another app. Responsive Mockup Studio follows Android WebView and website security rules.
