# Microsoft Store listing draft

## Product name

Responsive Mockup Studio

## Short description

Turn live responsive websites into presentation-ready device mockups.

## Description

Responsive Mockup Studio connects a live Chromium website preview with configurable desktop, laptop, tablet, and phone frames. Test responsive sizes, adjust device appearance and composition, save reusable custom devices, and export the result shown in the preview as PNG, transparent PNG, JPG, WebP, or SVG.

The Windows edition provides the complete embedded Chromium workflow for websites that restrict normal browser iframe access. Projects, bookmarks, recent URLs, saved devices, and preferences remain in the local application profile.

## Features

- Desktop, tablet, phone, automatic, and custom viewport sizing
- Editable device colors, materials, supported parts, shadows, and backgrounds
- Multi-stop linear and radial gradients
- Saved custom devices and preset-frame favorites
- 1:1, 4:5, and 16:9 output framing
- High-resolution raster and font-independent SVG export
- Scrollbar, cursor, animation, page-background, custom CSS, and safe page-element controls
- No account, advertising, analytics, or subscription
